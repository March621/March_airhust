### 连续性验算（讲义 1.5 要求）

外圈公式是 `p_R*(R_out−ρ)`，内圈公式必须**包含外圈那一项**，否则边界处会跳变。

| 交界处           | 外圈公式                               | 内圈公式                                        | 是否连续      |
| ------------- | ---------------------------------- | ------------------------------------------- | --------- |
| ρ = R_outside | `p_R*0 = 0`                        | 不适用                                         | 与"无作用区"接上 |
| ρ = R_inside  | `p_R*(R_out−R_in) = （填写，示例 0.315）` | `p_R*(R_out−R_in)+p_r*0 = （同上）`             | 相等 → 连续   |
| ρ → 0         | —                                  | `p_R*(R_out−R_in)+p_r*R_in = （填写，示例 1.665）` | 最大斥力      |

## 四、Stage 4：算法不足与改进

局部最优问题，也就是上面出现的飞机卡住不动的问题（这个人调了很久的参数才突然意识到这个算法本身就有问题）

- **成因**：引力（指向目标）与斥力（背离障碍）共线反向、大小相等时合力为零；本场景中两者上限都取 0.30，饱和后更容易抵消
- **我观察到的情况**：飞机，卡了！
- **我的方案**：先判断是不是真卡了，再根据斥力的方向添加一个切向的扰动
- **局限**：飞机弹道偏左
